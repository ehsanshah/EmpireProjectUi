## Exact implementation slice after contract decisions

1. IAM/Backend settle real identity provider, cookie/session lifecycle, BFF→Engine principal exchange, CSRF/Origin policy, logout and authorized staging fixtures. Implement same-origin BFF session/bootstrap and browser scope cleanup, then prove 401/403/logout and no exposed Engine bearer.
2. Bind project directory/detail and capabilities from authorized sources. Prove current permission revision and project switch/late-response isolation.
3. Replace UI-only search call with typed Engine `ViewQuery` translation for supported controls. Preserve counts, cursor, watermark, snapshot_changed, row metadata and permission scope. Explicitly disable unsupported text/group/archive controls until contracted. Prove independent seeded totals across pages.
4. Add authorized key/alias resolution or explicitly disable key deep links. Map detail and available transitions into new typed Live models without casting a Demo `Issue` source. Prove denied/ambiguous key behavior.
5. Reconcile required-field transition schema/atomic payload. Until then permit only verified field-free transitions. Bind ETag, idempotency, CSRF/Origin, typed Problem and receipt. Prove stale/missing-field/duplicate outcomes.
6. Map history and work-core command lookup with route/project validation; verify receipt audit_ref against history event. No 202 branch without operation schema. Prove dropped-response recovery with the same key.
7. Implement BFF SSE proxy and typed event mapper, cursor replay/reset, permission purge and bounded reconnect. Prove cross-project isolation, duplicate/version gap and revoke behavior.

**Owners/inputs:** IAM/Security—identity, session and BFF authorization design/test principals; Engine—key resolver, required-field screen/command contract, supported query controls, sample Problem/receipt/SSE payloads; DevOps—same-origin staging routing and non-production fixtures; Product/QA—independent expected counts/transitions. Local contracts do not establish Live readiness.
