# Phase 14 organization boundary — local Demo only

The organization routes in the reference contract are proposed surface names, not verified Engine operation IDs. `DemoOrganizationAdapter` is explicitly local. It projects current `DemoCoreClient` issues/activity, `DemoIntakePlanAdapter` questions, `DemoAgentRunAdapter` Runs/reviews/operations and `DemoPhase13Adapter` project membership/review policy. It stores only local Inbox read/snooze markers and idempotency records, not duplicate tasks or notification content. `u-sara` in the canonical fixture is the explicit assignment alias for the Demo session principal `sara-farahani`; no Live identity mapping is inferred.

Search resolves visible project IDs/keys/names and issue IDs/semantic keys (including `#KEY`) before title matches. Ambiguous names show separate results. The local policy lens filters projects, issues, snippets, counts, Inbox and activity on each read. Scope switches remove selection, locally cached markers and project streams; late project UI reads are ignored. This is **not evidence of server authorization or signed URL revocation**. There is no organization event stream; Inbox polls every 15 seconds while open. No Email/Slack/WhatsApp adapter or external send is active. Review responses use the existing versioned review decision command; Intake/Run questions open their existing context for permitted handling.
