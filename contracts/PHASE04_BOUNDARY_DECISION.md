The actual Engine OpenAPI, event schemas, staging endpoint, BFF session and test identities remain unavailable. The typed `CoreClient` exposes `getBoardSnapshot` and `placeBoardCard`. Its Demo implementation returns a workflow revision, mapped status columns, swimlanes, project-wide WIP policy/count, exact project count and rank revision. Placement carries issue ETag, rank revision, neighboring rank anchors, required fields, CSRF token and idempotency key. A successful Demo write returns a receipt, updates activity and emits a project-scoped event. Rejected WIP, required fields, stale item version and stale rank leave the card in its source position. The UI preserves a reviewable move draft after required-field or conflict errors.

The Work Flow is a local authorized projection of four Demo issues and four dependency edges. It exposes two converging paths, redacts hidden prerequisite labels, derives readiness and never mutates status, review acceptance or release state from that derivation. A direct status change in the drawer uses the shared validated transition command. No dependency write endpoint has been invented or enabled.

`src/core/httpClient.ts` contains a **proposed** same-origin Board snapshot read; its board placement method explicitly refuses Live writes. `createLiveCoreClient()` remains fail closed and never substitutes Demo data. The proposed reference lists Board configuration/items/rank operations but does not establish actual operation IDs or whether a move is one combined transition-and-rank command or multiple atomic operations. Before enabling Live, Backend must supply the actual Board/workflow mapping and WIP policy schemas, full-scope count semantics, conditional placement/transition and rank revision behavior, required-field error shape, receipt/idempotency/operation behavior and dependency visibility projection. IAM/Backend must supply BFF session, CSRF, permission scopes and redaction rules. DevOps must supply reachable non-production staging. Exit evidence is reconciled typed client plus authenticated staging tests for 409/412/422, WIP scope, rank anchors, receipt replay and hidden dependencies.

Status: **proposed and Demo verified; Live blocked**. Owner: Backend, IAM and DevOps. No reference contract was edited to imply agreement.
