# دروازه تأیید نمونه اولیه

وضعیت اولیه: `not_built`

چرخه مجاز: `not_built → building → awaiting_prototype_review`.
در صورت اصلاحات: `awaiting_prototype_review → revising → awaiting_prototype_review`.
فقط پیام صریح کاربر مبنی بر تأیید نمونه، مجوز ثبت `prototype_approved` است.
اجرای موفق تست، سکوت کاربر، بازشدن صفحه یا اتمام کدنویسی تأیید محسوب نمی‌شود.

این بسته ابتدا برای بررسی پرامپت تهیه شده است. اجرای پرامپت Stage 1 توسط کاربر
مجوز ساخت نمونه است؛ مجوز توسعه کل محصول نیست.

پس از تحویل نمونه، فقط اصلاحات همین مرحله انجام شود. مرحله بعد با درخواست کاربر
دامنه‌بندی می‌شود. تأیید ظاهر یا تعامل، به‌تنهایی مجوز اتصال Engine، انتشار عمومی،
پرداخت، ارسال پیام یا اتصال حساب‌های واقعی نیست.

مرجع محدودکننده دامنه این اجرا، درخواست جدید کاربر و PROTOTYPE_SCOPE است؛
برنامه بزرگ‌تر سند نسخه ۳، بک‌لاگ آینده است.
