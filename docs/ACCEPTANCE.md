# معیارهای پذیرش Stage 1

تمام شمارش‌ها در حالت Reset demo سنجیده شوند.

| ID | آزمون | انتظار |
|---|---|---|
| P01 | شروع از Today و فرمان مانده‌ها | تغییر Main workspace؛ دقیقاً ۶ رکورد |
| P02 | فقط مسدودها | EMP-103 و EMP-104؛ Count=2 |
| P03 | گروه‌بندی مسئول | همان دو شناسه؛ بدون تکرار یا حذف |
| P04 | تغییر List/Board/Timeline | Query و شناسه‌ها ثابت؛ EMP-104 در Unscheduled |
| P05 | بازکردن EMP-104 و برگشت | Drawer بسته؛ state قبلی و Focus حفظ |
| P06 | برگشت مجدد | نمای قبل در History؛ هیچ Issue تغییر نکرده |
| P07 | همه کارهای اسپرینت | ۱۲ رکورد؛ cancelled در مانده‌ها حساب نشده |
| P08 | فرمان ناشناخته/نوشتاری گروهی | بدون تغییر داده؛ پیام صادقانه و راه ادامه |
| P09 | Inline edit مسئول یا Status | یک تغییر محلی، نتیجه در نماها، Undo و Reset |
| P10 | دو فرمان با تأخیر معکوس | آخرین درخواست حاکم؛ پاسخ قدیمی صفحه را برنگرداند |
| P11 | empty در برابر error | صفر با فیلترها در برابر خطا با Retry؛ قابل تفکیک |
| P12 | fa/en و light/dark | layout صحیح، خوانایی متن/کلید، تقویم بدون تغییر روز |
| P13 | keyboard/mobile | Cmd/Ctrl+K، Escape، Focus و عرض ۳۹۰ قابل استفاده |
| P14 | فقط توضیح بده | پاسخ توضیحی؛ ViewState بدون تغییر |
| P15 | بدون سرویس خارجی | نصب/اجرا محلی؛ نیاز نداشتن به credential یا LLM |

تست خودکار معنادار: query evaluator برای ۶/۲/۱۲، follow-up state، History،
stale response، unknown intent و مسیر اصلی UI با ابزار موجود مخزن.
اگر مرورگر تست در محیط قابل اجرا نیست، blocker را ثبت کن؛ آزمون اجرا‌نشده را Passed نزن.
Build و Typecheck باید اجرا شوند؛ محدودیت محیط با خطای واقعی گزارش شود.
اسکرین‌شات در صورت دسترسی: Today RTL روشن، ۶ کار، Timeline دو کار با بدون‌تاریخ،
Drawer و یک نمای انگلیسی تاریک. تصویر خروجی UI واقعی باشد.

کاربر در بازبینی به ظاهر، خلوت بودن، راحتی فرمان‌ها و صحت نتایج نظر می‌دهد.
قبولی تست‌ها جای تأیید کاربر را نمی‌گیرد.
