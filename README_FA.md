# بسته شروع Codex برای EmpireProject

این بسته سورس نهایی اپلیکیشن نیست؛ دستورهای پروژه، fixture، سند مرجع و پرامپت
ساخت نمونه را شامل می‌شود. اجرای پرامپت توسط Codex سورس نمونه را تولید می‌کند.

## استفاده
1. ZIP را باز کنید. محتویات پوشه EmpireProject_Codex_Starter را در ریشه پوشه پروژه
   کپی کنید؛ همان پوشه‌ای که Codex روی آن کار می‌کند، نه پوشه تنظیمات سراسری ~/.codex.
2. اگر AGENTS.md از قبل دارید، آن را بازنویسی نکنید؛ قواعد بسته را با دستورهای موجود
   ادغام کنید. در تعارض واقعی تصمیم بگیرید؛ فایل‌های موجود پروژه را حذف نکنید.
3. برای بررسی قبل از اجرا، prompts/01_BUILD_PROTOTYPE_FA.md را بخوانید.
4. پس از تأیید پرامپت، همان پوشه را در Codex باز کنید و محتوای آن فایل را Paste کنید.
   یا بنویسید: «prompts/01_BUILD_PROTOTYPE_FA.md را بخوان و فقط همان مرحله را اجرا کن.»
5. Codex باید دستورهای نصب و اجرا را متناسب با پروژه در گزارش تحویل بدهد.
   برای پروژه جدید پیش‌فرض: npm install، سپس npm run dev. قبل از تولید سورس این
   دستورها قابل اجرا نیستند؛ package.json را Codex هنگام ساخت نمونه تولید می‌کند.
6. سناریوهای docs/ACCEPTANCE.md را در مرورگر ببینید. بازخورد را با پرامپت 02 بدهید.
   فقط پس از تأیید صریح نمونه، دامنه مرحله بعد تعیین و اجرا می‌شود.

## محتویات
| مسیر | کارکرد |
|---|---|
| AGENTS.md | دستورهای ماندگار پروژه و محدودیت مرحله |
| prompts/01_BUILD_PROTOTYPE_FA.md | پرامپت تولید اولیه |
| prompts/02_REVISE_PROTOTYPE_FA.md | اصلاح نمونه بدون گسترش دامنه |
| docs/PROTOTYPE_SCOPE.md | تعریف دقیق نمونه |
| docs/APPROVAL_GATE.md | توقف تا تأیید شما |
| docs/ACCEPTANCE.md | چک‌لیست بازبینی |
| docs/EmpireProject_UIUX_Architecture_Spec_FA_ver3.md | سند کامل و پژوهش قبلی |
| fixtures/sprint12.json | داده ساختگی ثابت برای نتیجه قابل آزمون |

نیازی به تغییر config.toml، اجرای خودکار shell یا افزودن کلید API ندارید.
در اولین مرحله، برد و تایم‌لاین برای مشاهده و پیمایش‌اند؛ گانت کامل و اتوماسیون آینده‌اند.

مبنای ساختار دستورهای پروژه: راهنمای رسمی OpenAI، بررسی‌شده در 2026-10-22:
https://developers.openai.com/codex/guides/agents-md/
AGENTS.md برای قواعد کوتاه پروژه است؛ Spec حجیم جدا نگه داشته شده و صریحاً ارجاع دارد.
