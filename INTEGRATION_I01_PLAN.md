## I01.1 Session

- **Frontend:** `LiveCoreClient.bootstrap()` in `src/core/httpClient.ts`; `Session`/`CoreBootstrap` in `src/core/contracts.ts`; fail-closed entry in `src/main.tsx`.
- **Required operation/schema:** browser `GET /api/session` returning principal, authorized org selection/memberships, locale/timezone, expiry, CSRF token and permission revision; logout/expiry/revocation behavior. `GET O/capabilities` also needs a reconciled source or explicit capability-limited bootstrap. Neither is in the discovered Engine OpenAPI; do not treat `/v1` bearer auth as a browser session.
- **Auth/CSRF/version/idempotency:** HttpOnly/Secure/SameSite cookie and Origin policy are BFF responsibilities. CSRF token is issued for later writes; session read itself has no `If-Match` or idempotency key. Session/grant revision must invalidate scoped state on change.
- **Missing input:** IAM/Backend decide OIDC or other provider, session renewal/logout, org switch, CSRF error schema and BFF envelope; DevOps supplies same-origin non-production routing and least-privilege identities. Backend discrepancy D-013 remains open.
- **Acceptance/evidence:** valid, expired and revoked sessions; cross-org denial; logout clears cache/streams/selection; browser assets and logs contain no bearer or cookie value. Capture redacted HTTP exchange, BFF contract, security test log and UI state before/after expiry.

- **Frontend:** `subscribe()` in `src/core/httpClient.ts`; `CoreEvent` in `src/core/contracts.ts`; `ScopedEventReducer` in `src/core/eventReducer.ts`; subscription lifecycle in `src/App.tsx`.
- **Required operation/schema:** Engine `projectEventStream` (`GET /v1/orgs/{org}/projects/{project}/events`), SSE `StreamEvent`, opaque `id` cursor and `Last-Event-ID`/`after` resume. Actual event names include `work_item.created.v1`, `work_item.transitioned.v1`, `stream_reset`, `access_revoked` and `stream_unavailable`; UI currently listens for `WorkItemUpdated`/`PermissionChanged`/`stream_reset` and expects camelCase. - **Auth/CSRF/version/idempotency:** same-origin session cookie to BFF, no bearer or secret in event URL; GET stream has no CSRF write token or idempotency key. Recheck permission per batch and compare `permission_revision`; close stream and purge scoped cache on revoke/org switch/logout. Use aggregate version for gap/duplicate handling.
- **Available vs missing:** backend SSE contract, Go route and reported integration test for replay/revocation exist. BFF streaming/proxy behavior, browser cookie session, heartbeat/idle policy and permission-change propagation across services remain unverified.
- **Acceptance/evidence:** two projects show no cross-scope event effect; duplicate/out-of-order/gap causes at most one invalidation or authorized refetch; reconnect from cursor resumes; expired cursor resets snapshot; revocation closes stream and removes restricted content. Capture redacted SSE frames/cursors, browser cache state and backend test log under an authorized staging identity.
